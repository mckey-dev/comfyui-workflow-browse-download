## Workflow Browse Download

## 概要

ComfyUI のワークフローブラウズ画面の右クリックメニューに「ダウンロード」を追加するフロントエンド拡張です。ノードは追加しません。

## 機能

- ワークフローブラウズ / 検索パネルの保存済みワークフローを右クリックして JSON を保存する
- 一時ワークフローは対象外

## インストール

`custom_nodes` にこのフォルダ `comfyui-workflow-browse-download` を置き、ComfyUI を再起動してください。

## 使用方法

1. ComfyUI を起動する
2. ワークフローブラウズまたは検索パネルを開く
3. 保存済みワークフローを右クリックする
4. 「ダウンロード」を選ぶ
